# Google - Custom Web Browser

A sleek, customizable web browser built with HTML, CSS, and JavaScript. Browse the web, bookmark your favorite sites, and enjoy a beautiful interface.

## ✨ Features

- 🌐 **Address Bar** - Enter any URL to browse websites
- 📌 **Bookmarks** - Save and manage your favorite websites
- ⏪ **Navigation** - Back, Forward, and Refresh buttons
- 🎨 **Custom Themes** - Beautiful animated JavaScript backgrounds with gradient shifts
- 💾 **Local Storage** - Your bookmarks persist across sessions
- 📱 **Responsive Design** - Works on desktop and tablet
- ⚡ **Loading States** - Visual feedback with loading spinner
- 🔍 **Search Integration** - Auto-detect URLs or search with Google
- 🎭 **Glassmorphism UI** - Modern frosted glass aesthetic

## 🚀 Getting Started

1. Clone the repository or download the files
2. Open `index.html` in your web browser
3. Start browsing!

## 📖 Usage

### Browsing
- Type a URL in the address bar and press **Enter**
- Examples: `google.com`, `roblox.com`, `youtube.com`
- If no protocol is specified, `https://` is automatically added
- Searches without a domain are directed to Google Search

### Bookmarks
- Click the **⭐** icon to bookmark the current page
- Click a bookmark to quickly return to that site
- Use the **✕** button next to each bookmark to remove it
- Click **Clear All** to remove all bookmarks at once

### Navigation
- **Back** (←) - Go to the previous page
- **Forward** (→) - Go to the next page
- **Refresh** (⟳) - Reload the current page
